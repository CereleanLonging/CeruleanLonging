# Code signing policy / 代码签名政策

[简体中文](#zh) · [English](#en)

<a id="zh"></a>

## 简体中文

CeruleanLonging 的维护者和产品发布者为 **lantu**（GitHub：[CereleanLonging](https://github.com/CereleanLonging)）。0.1.35 处于**公开预览**阶段，安装包**未签名**。

项目现阶段不申请代码签名；SignPath 申请已停止推进，未取得申请接收确认、审核批准或签名证书。签名不属于本次功能验收要求。

请从[官方发布页](https://github.com/CereleanLonging/CeruleanLonging/releases/tag/v0.1.35)获取安装包。附件 BUILD-AND-CHECKSUMS.json 提供文件摘要和构建信息，可用于核对下载文件；哈希校验不等同于可信代码签名。Windows 可能显示“未知发布者”，产品元数据中的 lantu 不代表已通过证书验证。

第三方组件保留各自许可证及原有签名。具体功能范围见 [支持范围](SUPPORT.md)，数据和外部服务使用见 [隐私说明](PRIVACY.md)。

<a id="en"></a>

## English

CeruleanLonging is maintained and published by **lantu** ([CereleanLonging on GitHub](https://github.com/CereleanLonging)). Version 0.1.35 is a **public preview**. Its installer is **unsigned**.

The project is not pursuing code signing at this stage. Work on the SignPath application has stopped; receipt of the application, approval, and a signing certificate have not been confirmed. Signing is outside this functional acceptance scope.

Obtain the installer from the [official release page](https://github.com/CereleanLonging/CeruleanLonging/releases/tag/v0.1.35). The BUILD-AND-CHECKSUMS.json attachment provides file hashes and build information for checking downloads; a matching hash is not a trusted code signature. Windows may display “Unknown publisher”; the lantu product metadata is not certificate-verified identity.

Third-party components retain their licenses and existing signatures. See [Support scope](SUPPORT.md) for feature coverage and the [Privacy notice](PRIVACY.md) for data and external-service use.
