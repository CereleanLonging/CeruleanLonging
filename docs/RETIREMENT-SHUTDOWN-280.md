# 280 明确结束提交后的退出判定

279实机在记录用户结束提交、原运行superseded后，正常退出仍返回unresolvedTasks。保留Submitted字段是既有设计，用于保留实际提交事实；缺口在退出判定没有识别这一明确处置。

修复只允许当前方案已有经过本机用户认证的 `RetireSubmittedPlan` 事件、摘要与当前revisionRequested一致时，把保留的Submitted视为可退出。普通暂停、放弃指挥回复、普通修订、其他方案的结束事件均不替代该证据。运行中进程、未知执行器、恢复和其他既有退出关口保持。

新增回归沿真实宿主、文件工具和独立验证器执行，模型响应受控：收口不可用后只放弃回复仍不能退出；明确结束提交后可退出，原Submitted/verified/产物/历史完整保留，重开不发送。此检查已通过；格式及严格Clippy结果见本批latest.json。
