## 配置与兼容

新增可选 `acceptance` 配置，格式版本为1，支持1–8项检查。每项包含稳定ID、用户可读名称、已登记工具、参数及单项时限。名称最多160字节，不能有控制字符；参数每项最多32个、每个最多4096字节，全部检查参数合计最多16KiB；单项时限1–3600秒，合计不能超过已有执行总时限。所有检查均为必需项。

旧配置没有 `acceptance`，旧 AcceptanceCheck 没有 `name`；读写序列化均省略缺省字段，旧摘要及批准保持。新配置保留原单项字段作为第一项的兼容投影，核心要求两者严格相等，不能只修改其中之一。新格式的每项工具绑定都与登记记录核对，不能只核对首项。旧程序无法理解新配置时应拒绝，不允许删除新字段冒充降级。

用户保存新配置时产生不可变的新版本。主指挥输出仍引用配置的首项工具ID，核心将用户完整有序列表物化到每个任务；模型不能自己扩充检查命令。每项名称、顺序、参数、时限及工具摘要都进入 PlanRevision 和批准摘要，持续执行门禁比较完整列表。项目仍共用一套验收配置，尚未实现各任务分别选择不同检查列表。

界面支持添加、删除、上移、下移，显示时限合计；超过总时限时禁用保存，核心独立验证全部限制。批准对话框逐项按顺序展示名称、命令、时限及固定工具证据。保存配置和批准方案均不会自动启动项目。
