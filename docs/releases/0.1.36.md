# CeruleanLonging 0.1.36 · 公开预览 / Public Preview

Windows x64 · Publisher: **lantu** · MIT

## 简体中文

- Codex 接入窗口新增“扫描本地 Codex”，查找正在运行的程序、PATH、当前账户安装位置、npm 和 WindowsApps 中的常见安装布局。也可以填入具体安装目录后扫描。
- 扫描只发现候选位置，不读取凭证、启动候选程序或发起模型请求。用户选用路径后，仍需单独点击登录检查。扫描有条目、结果数量及时间检查限制，不遍历整个磁盘。
- 拒绝把安装文件夹、应用执行别名、链接路径或 Codex 桌面启动程序当作命令行程序，提供中文说明。原路径保护继续保留。
- 工作台通用错误展示增加中文解释；原始诊断可在“技术详情”中展开。原日志和失败记录不改写，超时或送达未知不会被显示为已完成。

本版继续公开预览，沿用 reader19 数据格式；更新前请备份。盲评、供应商验证和其他能力边界仍按 [支持范围](../../SUPPORT.md) 说明。更换程序路径后，旧路径的登录结果不会被视为新路径已通过检查。

## English

- Added local Codex discovery for running programs, PATH, per-user installations, npm, and common WindowsApps layouts. A specific installation directory can also be supplied.
- Discovery only lists candidates. It does not read credentials, launch candidates, or send model requests. Choosing a path remains separate from checking login. Entry, result, and elapsed-time checks bound scanning; it is not a recursive disk search.
- Installation folders, execution aliases, links, and desktop launchers are rejected as CLI executables, with actionable Chinese messages. Existing path protections remain in place.
- Common workbench errors now show Chinese explanations with expandable original diagnostics. Logs and failure records remain intact; timeouts and unknown delivery are not presented as completed actions.

This remains a public preview and retains reader19 data support. Back up before updating. Blind-review and provider-validation limits remain as described in [Support scope](../../SUPPORT.md). Changing the executable path invalidates the displayed connection result for the old path.
