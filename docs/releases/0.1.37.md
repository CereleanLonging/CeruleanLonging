# CeruleanLonging 0.1.37 · 公开预览 / Public Preview

Windows x64 · Publisher: **lantu** · MIT

## 简体中文

- 点击窗口关闭或“退出工作台”后先确认。后台核心通过原身份连接正常停止，核实原进程退出后才关闭窗口。已保存数据和凭证保留，未保存编辑会丢失。
- 退出时暂停当前窗口的新请求和自动连接，并等待原请求返回，避免后台刚停止又被刷新重新拉起。运行中或结果未确认的任务会阻止退出；失败保留窗口，不强杀、不自动重试。
- 独立维护窗口须先正常关闭；其他实验工作台和外部模型应用各自管理。这里只停止当前工作台对应的核心，不删除工作目录或用户数据。
- “创建计划”与项目需求新增“导入本地 Markdown 文档”，只支持 UTF-8 `.md`，先预览再确认替换草稿。读取和导入不自动保存、调用模型、批准或启动任务。
- 手工计划用首个非空行的一级标题作为名称（否则使用文件名），其余非空行各为一项任务。保留现有 1–30 项、每项 2000 字节限制；项目需求最多 8000 字节，文件最多 64 KiB。超限拒绝，不截断内容。
- 文档按纯文本处理，不执行 HTML、代码或外部链接。切换项目、编辑草稿或改变可用状态后，旧预览和迟到的读取结果失效。

沿用 reader19 数据格式，更新前请备份。供应商与盲评范围见 [支持范围](../../SUPPORT.md)。本轮不增加真实供应商质量结论。

## English

- Closing a window or choosing “Exit workbench” asks for confirmation. The associated core is stopped through its authenticated connection, and the original process must exit before the window closes. Saved data and credentials remain; unsaved edits are lost.
- Exit fences new requests and automatic connections from that window and drains original requests, preventing refreshes from restarting the core. Running or unresolved tasks block exit. Failures keep the window open without force termination or automatic retries.
- Close independent maintenance windows normally first. Other experiment workbenches and external model applications keep their own lifecycle. Exit does not delete project directories or user data.
- Create Plan and project requirements can import local UTF-8 `.md` files only. Preview and confirm replacement of the draft; import does not automatically save, call a model, approve, or start a task.
- Manual plans use an initial H1 as the title, or fall back to the filename. Remaining nonempty lines become tasks. Existing limits remain: 1–30 tasks, 2000 bytes per task, 8000 bytes for project requirements, and 64 KiB per file. Oversized content is rejected, never truncated.
- Markdown remains plain text: no HTML, code, or external links are executed. Changed projects, drafts, or availability invalidate older previews and late read results.

Reader19 data support is retained. Back up before updating. See [Support scope](../../SUPPORT.md) for provider and blind-review limits. This update adds no live-provider quality claim.
