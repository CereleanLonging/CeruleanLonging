# CeruleanLonging 0.1.42

发布者：lantu · Windows 公开预览 · 自有代码 MIT

## 中文

新增“独立实验工作台”导航页，位于“维护与升级”上方。每次打开工作台默认关闭，勾选“开启独立实验功能”后展开工作台创建与切换、团队效率验收和单执行者效率验收。原侧栏按钮与需求页中的效率实验表单移入此页。未开启时不读取实验目录或实验完整视图；开启不创建实验或发送任务，取消勾选只收起功能，不停止已运行的实验。

全局 API 中断复核记录与全局管理复核记录现在统一放在“维护与升级 → 只读日志”。点击入口会打开独立窗口，通过两个分类页签查看原记录、翻页或刷新，工作总览及需求页不再展示原来的两个入口。

日志窗口仅允许读取这两类记录，不能提交项目操作、批准、重试或启动维护。所属工作台由原生窗口身份绑定，实验工作台的日志不会切换到主工作台。原记录、分页版本与详情身份校验沿用既有机制；读取失败明确显示未知，不视为没有日志。

重复打开会复用该工作台的日志窗口。关闭日志不停止任务；正常退出所属工作台时，原核心按既有流程停止，日志窗口一并关闭。日志刷新仅连接已运行的核心，不会自动启动或重启后台。本版不变更数据格式。

## English

Publisher: lantu · Windows public preview · Original code under MIT

An Independent Experiment Workbench navigation page now sits above Maintenance & Upgrade. Its features default to off whenever a workbench window opens. Opting in reveals inline creation and switching, team efficiency experiments and single-executor baselines, replacing the previous sidebar button and requirements-page forms. While off, the page does not read experiment catalogs or full experiment views. Opting in creates no experiments or tasks; turning it off hides the controls without stopping existing experiments.

Global API interruption and management review records now share a separate window under Maintenance & Upgrade → Read-only Logs. Two tabs provide original-record details, pagination and refresh. The former entry buttons are removed from the overview and requirements pages.

The window may read only those two record categories. It cannot submit project operations, approve, retry or launch maintenance. Native window identity binds it to its owning workbench, keeping experiment logs separate from the main workbench. Existing record, pagination revision and detail identity checks remain in place. Read failures remain unknown rather than being reported as empty logs.

Reopening focuses the existing log window for that workbench. Closing logs leaves tasks running; normal owner exit stops its core through the existing flow and closes its logs. Log refresh only connects to a running core and never automatically starts or restarts it. This update makes no data-format change.
