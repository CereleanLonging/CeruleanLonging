# CeruleanLonging 0.1.35 · 公开预览 / Public Preview

Windows x64 · Publisher: **lantu** · MIT

## 简体中文

本版将角色目录隔离与项目盲评带入工作台，保留任务级客观检查、主指挥接受及用户最终确认。

- 主指挥需求独立保存，副指挥只读核对；执行身份在共用总目录下使用各自固定子目录，上限五个，支持模型替换和目录复用。
- 新隔离任务的 CLI、桌面及客观检查使用普通 Windows 账户，检查副本的临时权限在进程退出后回收。
- 新增无工具 API 盲评：用户审阅脱敏分片材料及名册，副指挥确认就绪，各席一票，完整揭晓；全票后由用户确认同一交付。不通过或要求修改时接回原方案修订流程。
- 修复并行调度把旧方案的失败检查错误套用到新尝试的问题；保留当前失败的阻断和历史记录。
- 移除 WorkBuddy 新接入与执行支持，旧记录保留。更新中英文介绍和能力说明。

**升级与范围：** 建议先备份并在独立实验工作台试用。启用盲评后要求 reader19，不可用旧核心打开新格式；同一数据目录的旧宿主权限执行配置和外部聊天主指挥不兼容此模式。仅无工具 API 可以参评，CLI/桌面暂不支持盲评。完整材料最多 96 KiB、128 个源码文件，每片最多 2,048 UTF-8 字节；超限明确拒绝。

**验证：** 新机制完成本地协议、界面、恢复、调度回归及真实普通 Windows 账户边界验证，使用合成模型回包，没有新增真实供应商质量结论。脱敏不能保证消除任意暗号。0.1.34 的原验收、失败和延期记录保留；本版继续公开预览，不作稳定版承诺。

发布附件包含 Windows 安装器、源码归档及 `BUILD-AND-CHECKSUMS.json`。校验文件记录源码提交、构建身份和 SHA-256；安装器未签名，摘要不等同于可信签名。

## English

This release adds role-directory isolation and project blind review while retaining objective task checks, lead acceptance, and final user confirmation.

- Lead requirements are stored separately for read-only coordinator review. Workers use fixed identity directories under a shared root, with up to five directories, model replacement, and directory reuse.
- CLI, desktop, and objective checks for new isolated tasks use standard Windows accounts. Temporary access to checking copies is revoked after process exit.
- Tool-free API blind review lets users approve redacted, fragmented material and a roster. After coordinator readiness, each seat casts one vote; complete results are revealed together. Unanimity requires user confirmation of the same delivery. Rejection or requested changes return to the existing revision flow.
- Fixed parallel scheduling incorrectly applying an old plan's failed check to a new attempt. Current failures still block and historical records remain intact.
- Removed new WorkBuddy integrations and execution while retaining historical records. Updated bilingual documentation and support notes.

**Upgrade and scope:** Back up first and try an experiment workbench. Enabling review requires reader19; older cores cannot open the new format. Legacy host-account execution and external current-chat leads in the same data directory are incompatible with this mode. Reviewers must use tool-free APIs; CLI/desktop review is not supported. Material is limited to 96 KiB and 128 source files, with 2,048 UTF-8 bytes per fragment; oversized inputs are rejected.

**Validation:** Local protocol, UI, recovery, scheduler regression, and real standard Windows account boundary checks use synthetic model responses. No new live-provider quality conclusion is claimed. Redaction cannot guarantee removal of arbitrary covert signals. Original 0.1.34 acceptance, failure, and deferred records remain intact. This remains a public preview, not a stable-release commitment.

Assets include a Windows installer, source archive, and `BUILD-AND-CHECKSUMS.json` identifying the source commit, build, and SHA-256 hashes. The installer is unsigned; checksums are not trusted signatures.
