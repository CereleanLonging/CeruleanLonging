# CeruleanLonging 0.1.48

Windows x64 公开预览，发布者 lantu，自有代码采用 MIT 许可。

## 本次更新

- 补齐逐执行端独立检查与整体盲评之间的交接。独立检查确认各执行端成果的完整性并运行批准的测试，失败结果反馈副指挥返工。全部合格并接受后，核心汇总只读交付与报告，再交独立盲评。主指挥整体功能测试在盲评达标后开放。
- 盲评材料增加独立进程生成的匿名检查结果摘要。源码继续脱敏分片，投票和总分按原隔离规则管理。新材料使用 reader24 保护。
- API 执行端评审沿用已批准的输出额度，逐席展示并绑定本轮批准摘要，相应轮次使用 reader25。
- Codex 评审识别原消息之前的自动历史压缩事件，继续核对原输入、完整记录和工具调用。API 评审显式列出批准标准的编号，避免将子测试或段落误作额外评分项。
- 增加桌面升级适配。Codex 原程序路径随升级消失时重新定位，发现多个候选时提供明确选择入口。Qoder 同协议系列的新版本先验证当前会话，再重新绑定和批准任务。版本、进程、路径、模型及桥接程序的变化都会影响验证资格。
- 修复独立检查账户在长路径实验目录中创建失败的问题。Windows PowerShell 使用扩展路径执行文件与权限操作，账户记录继续关联完整项目路径。新增专项验证覆盖超过 260 字符的目录、字面路径和权限核对。
- 合并接入配置检查、保存和下一步操作，增加确认弹窗。日常工作台采用浅色项目栏，独立实验台采用深色项目栏。
- 需求、Markdown 和工作流导入合并为同一输入框。内置本地提炼支持长文档分段处理、原文定位和确认回填。管理员主窗口配有普通权限拖拽导入窗口。
- 项目工作记录支持流式刷新、模型筛选和历史回读。独立检查与盲评固定绑定各自程序，默认脱敏规则可补充自定义精确替换。
- 构建采用受管临时缓存、单 Cargo 任务、CPU 20% 上限和已验证的 3 GiB 构建额度，结束后自动清理缓存内容并保留提炼日志。

检查进程意外退出后，用户处置原复验时会核对原启动身份与进程退出状态，回收原检查目录的临时权限。恢复过程保存独立回执，支持中途收尾与重复核对，原失败结果和提交证据保留。

## 桌面升级范围

Qoder 的实际版本记录覆盖 0.4.3.0 和 0.4.8.0。0.4 同系列候选版本经过版本门禁及身份变化的合成回归，实际新版本仍须完成本机固定消息验证。跨协议系列需新增适配。升级时原任务结果未知，需要先核对原记录。

Codex 保留明确选择的有效程序路径。原路径消失后，完整扫描的唯一候选或唯一运行中 CLI 可以重新定位。接入仍需核验账号、协议与原会话。

## 升级数据

使用维护页备份当前数据。新盲评材料启用 reader24，绑定 API 执行端评审输出额度的轮次启用 reader25。打开这类数据需要支持对应阅读器代际的程序。历史轮次及失败记录保留。

## 验证记录

核心单元测试通过 1,104 项，另有 303 项忽略用例。核心命令行通过 66 项，14 组普通集成测试通过。23 项真实 Windows 普通账户测试通过，覆盖检查目录隔离、崩溃后显式权限回收和重复处置。适配器通过 168 项。编译与测试运行器的原失败回执保留。

真实服务实验采用双模块 JavaScript 合成项目，23 项项目检查断言通过。Codex 专用后台主指挥、A6API 副指挥、DeepSeek 执行端与 Qoder BYOK 桌面四席盲评通过，过程审计完整且无工具调用，随后完成主指挥整体功能测试和测试交付确认。前十轮失败或未完成记录保留，其中包含早期人工桌面协助及一次旧核心受控终止。

Qoder 回复读取加入有界只读等待，新增测试覆盖 UIA 刷新、历史暂缺、身份变化和超时。固定请求只发送一次。证据权重为初始值，校准状态为未知。模型质量结论限于本轮合成项目和实际使用配置。

最终安装器及源码包附有 SHA256SUMS.txt 和 BUILD-AND-CHECKSUMS.json。云端检查状态可在同一提交的 GitHub Actions 页面查看。
