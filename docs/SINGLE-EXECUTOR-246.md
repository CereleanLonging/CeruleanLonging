# 246 本地单执行者内核路径：受控检查通过

本轮补245交接中的无管理模型开销基线基础。已有API RuntimeHost路径要求原管理Assign；本轮没有伪造OpenAI/DeepSeek管理响应，也没有修改原API启动记录格式。

## 实现

`Workflow::new_single_executor`显式选择本地实验模式：只有唯一user/core/worker且无模型provider声明。用户提出一个无依赖、version1的任务并另行批准；核心分配一次、经独立验收后接受；worker只能按原工具/提交规则工作。禁止管理建议、修订、再次分配，不增加第二套调度器。普通Workflow构造器及OpenAI指挥绑定规则保持。

`SchedulerConfig::single_executor`使用独立bindings schema3。既有schema1/2序列化不改；schema3需要严格作用域、一个API执行者，无管理配置/监督策略/金额执行。继续使用原DurableWorkflow、API请求账本、文件工具、验收、恢复与交接。恢复沿用已核验工作流模式，普通团队仍按原模式重放。

新模式只是开发态库入口，尚未接入RuntimeHost启动事务、IPC/UI、实验运行器和来源导出。当前产品候选0.1.15未打包此改动。不要把schema3实验目录塞入普通团队项目，不能宣称旧安装版能读取它。旧代码只接受schema1/2的拒绝分支本轮查过；未运行旧二进制兼容实测。
