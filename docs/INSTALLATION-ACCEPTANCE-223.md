## 本次实际完成

新增 `scripts/review_nsis_payload.py`，只读解析当前 NSIS Unicode / solid-LZMA 安装包。它先校验指定清单与三个归档文件的摘要，再校验 NSIS CRC、压缩流终态、块边界及安装指令中的文件名与数据偏移；对两个主程序验证完整字节长度及 SHA256。没有执行安装器或其中任何程序。

当前 0.1.13 包通过：45,081,360 字节解压流、12 个块、1,937 条指令；`CeruleanLonging.exe` 和 `cerulean-runtime.exe` 各有唯一、对应正确内容的安装文件记录。检查同时设置输入、解压、字典和块数上限，不将解压文件落到安装目录。

14 项定向测试通过，覆盖错误清单、错位数据偏移、重复文件名、仅包含匹配字节的伪载荷、CRC 损坏、截断压缩、额外尾部、字典/解压上限及越界表/块。这些是核验工具的受控测试，不能算作产品的安装验收。

证据：`reports/nsis-payload-223/payload.json`、两组 `*.receipt.json`、`payload-tool-tests.stderr`、`result.json`。旧 222 报告和冻结包不改写。

可复用命令（输出文件必须尚不存在）：

```powershell
python -B scripts/review_nsis_payload.py --package reports/p6-windows-package-0113-20261020 --manifest-sha256 f65d2065eb0d84f909204362fa3814ca0182b23a94d5eb04d79aae6733c0b67b --output <新报告路径>
```

工具只支持本次审阅的未附加签名尾部的 NSIS 格式。正式签名后或打包格式变化时需重新审阅格式，不绕过拒绝。它不验证安装指令的运行分支、最终安装目录、动态生成的卸载程序、插件可信身份或 GUI 行为；其中的 NSIS 插件路径保留原始字符串编码，不将其当作已经展开的 Windows 路径。
