# WorkBuddy 接入移除

2026-11-03，按用户要求，从当前开发版本移除 WorkBuddy 接入与任务派发支持。桌面接入保留 Qoder；Codex、OMP 和模型 API 路线不因此变更。

- 新建项目和附加执行配置不再提供 WorkBuddy。已有配置明确显示“支持已移除”，需要用户选择其他执行器、保存新版配置并重新批准。
- 接入列表和原生窗口发现不再列出 WorkBuddy。后端拒绝新配置、规划、运行、独立应用登录及桌面读取、输入和停止动作；保留本地历史查看和未决记录处置。
- 历史类型、原批准摘要、旧模型目录登记、派发和检查证据继续保留。读取旧记录不等于允许恢复执行，也不会自动把原任务换绑给另一模型。
- 历史指挥请求使用其原供应商目录核对摘要。新请求不再向指挥列出 WorkBuddy；只有已知的旧目录版本可以用于历史核对，修改过的旧目录仍会被拒绝。

本轮 766 的独立账户实测在登录后由用户终止，未发送编程任务，不能记录为新隔离路线验收通过。测试应用、独立登录浏览器、临时账户及登录数据已退出或清理；用户日常 WorkBuddy 安装与数据未修改。

移除的是当前开发分支中的支持。已发布的 0.1.34 安装包保持原样，后续发布需使用完成检查的新构建。
