# 334：固定版本完整安装器升级执行链

本项继承 320 的材料核对、333 的修复与两份原候选，不重做接入或重新打包。入口在 `reports/full-nsis-upgrade-334/driver/`，只支持 310 / 0.1.21 → 315 / 0.1.22 的独立 Windows 验收；不是产品自动升级功能。当前检查结果以同目录上级的 `result.json` 为准；该结果未生成前，不应将本文理解为已通过。

## 执行和保留责任

1. 读取原准备计划、原机器指纹记录及固定摘要。真实执行时独立读取当前机器、账户、标准发行数据路径及模板选中的 WebView2 登记，要求当前机器与来源机器不同，且与用户声明的专用测试环境一致。合成环境只能通过测试的内部参数使用，CLI 没有此开关。
2. 在当前账户 Known Folder 的 `LocalAppData/CeruleanLongingAcceptance/full-nsis-v1` 按规范安装目录、数据目录分别取得稳定资源锁。锁不依赖运行目录、计划副本或脚本副本位置；一个资源冲突即拒绝。计划消费标记按计划 SHA256 保存，另外两个资源各有持久意图，启动前均需写入；重新生成计划摘要也不能绕过未核销操作。成功、失败或未知后都不删除这些记录，不自动重试；后续显式恢复必须关联原记录，不能手工删除绕过。
3. 持续固定包输入、冷备份、原 hold 和目录名称；父进程取得 writer 锁，重新核对完整计划、原安装与登记，再保存一次性启动意图及消费标记。安装目录内的原程序不跨安装期固定，避免阻挡 NSIS 替换。
4. 父 writer 锁交给 NSIS 自己的 share0 钩子，原 hold 和资源锁持续保持。安装器最多启动一次。启动前建立双路捕获；启动后证据发布、管道或等待错误不能成为重发理由。观察超时仍等待原句柄，保留超时事实，不杀进程。
5. 原进程终态、输出闭合后重取父 writer，核目标两程序、五资源、新观察到的卸载器、八格登记、原数据/hold/冷备份，并进行第二次库存观察。原句柄或证据链缺失、非零退出、超时、数据漂移均不走正常成功出口。
6. 全部锁及保护句柄正常退出后，最多发布 `internal-upgrade-verified-held`。hold 留在原处，不启动产品，不自动回退，不标正式验收通过。

Windows 的字节写锁会阻止另一句柄对空 `writer.lock` 的普通读取。334 在父 writer 作用域内，只对这个精确文件，通过另一个 metadata 句柄确认卷、文件 ID、单链接及零字节长度，然后提供标准空 SHA256；其他文件仍按原字节摘要流程读取。代理仅限 334 私有加载的 helper，离开作用域先恢复，再释放锁；333 冻结脚本不改。该约束面向合作式进程，不能证明任意外部写者或内存映射都受控制。

## 接口

- `run_full_nsis_upgrade.py capture-origin --output <新记录>`：只记录本机机器 GUID 的摘要；不安装。不要把合成测试的机器记录用于实际执行。
- `execute --plan <333准备计划> --plan-sha256 <摘要> --origin <来源记录> --origin-sha256 <摘要> --run <334下新的run-*目录> --allow-unsigned-internal`：仅供上述独立环境执行。默认 120 秒是首次观察间隔，不是强杀时限。两份固定包尚未正式签名，因此必须明确内部候选选项。
- `readback --report <post-install.json> --report-sha256 <摘要>`：只检查冻结证据连接，成功状态 `frozen-evidence-consistent-only`、exit0；不能从 JSON 重建进程、恢复执行权限或解除 hold。

这套脚本是一个进程中串行执行一次操作的验收工具；不同进程通过稳定资源锁协调。包/准备器/旧源摘要不一致时停止，不能手工删保护或改冻结材料“修复”差异。

## 未闭合范围

没有独立 Windows 上的真实 NSIS 安装证据；新卸载器只与原意图、原进程及后验库存关联，未声称密码学来源认证或全系统唯一安装写者。原工作主机不作安装、卸载、注册表或信任变更。

显式恢复仍需另行实现：核当前目标版本归属 → 将当前卸载器复制至隔离 runner → 原始 `/S _?=<安装目录>` 保数据卸载 → 核原数据/hold/备份与登记允许残留 → 用旧完整 setup 恢复。现有二进制替换工具不适用这次资源集合变化。320 关于静默降级必拒、静默升级必自动旧卸载的确定表述不作为依据；详见 `reports/full-nsis-upgrade-334/review/boundaries.md` 的精确来源与更正。

完整正式门槛仍沿用 318 的 27 项及 321 的 13 条接入配置。本文不关闭签名、干净 Windows、真实恢复、费用或剩余接入验收。
