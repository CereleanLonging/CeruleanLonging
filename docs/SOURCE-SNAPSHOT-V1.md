## 保留限制

- 此机制固定受测版本，不是 OS 沙箱。受信任程序仍可能通过绝对路径/动态依赖读取项目外内容，需要工具、脚本、依赖和环境策略进一步约束。
- 现有文件的运行期写锁不阻止一切目录创建活动。中间新建再删除文件、外部网络/系统服务等不应宣称已隔离。
- runner 结束后，留存文件靠摘要检测修改；不宣称同账户无法改磁盘。接受记录对应封存版本，原项目最终检查后的外部编辑仍需集成租约/原子发布控制。
- 当前 Windows 本机验证；跨平台、路径大小写边界、真实大型依赖树、空间不足及复制中断需继续扩充。复制容量有界，阻塞磁盘 I/O 未实现硬中止。
