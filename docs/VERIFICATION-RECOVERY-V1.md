## 产品行为

验收详情按需核对原方案、尝试、提交清单、执行意图、报告、阶段顺序、日志摘要和受测副本。对于待对账验收，只有当前任务仍是同一已提交尝试、没有活动执行器或未决管理请求、完整报告可核对、批准工具和当前输入仍匹配时，才显示“审阅补记结果”。只读审阅不推进调度。

用户确认时重新核对证据及工作流链头；旧审阅失效则拒绝。先持久暂停项目运行，再以原 operation 写入原始 Verify，保留用户确认摘要。补记不会重新运行检查、启动模型、自动 Accept 或派发后继任务。失败或超时报告只补记失败；部分阶段退出 0 不能补造完整报告。已放弃验收不允许补记。

Verify 是结果依据，状态文件是投影。账本提交后状态文件写入失败，重开可由原事件恢复；同一次确认重试不追加第二条 Verify。账本提交前失败则保持未确认，需要按当前证据继续处理。
