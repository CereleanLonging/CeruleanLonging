# OMP 受控文件服务 V1

2026-10-10。承接 [调用路由与持久记录](OMP-HOST-CALLS-V1.md)。Windows 核心新增 `OmpFileTools`，实现 `HostService` 并实际连接 `OmpToolJournal`。目前提供 UTF-8 读取和带版本检查的整文件写入，已通过合成 RPC 对端与真实本地文件联合测试。生产调度、真实 OMP 模型编程及命令工具尚未接入。

## 批准与范围

构造服务时核对用户批准、策略版本、计划修订摘要、任务、项目根、OMP provider/model，按 ReadFiles/WriteFiles 权限生成工具目录。调度器仍负责尝试身份、派发新鲜度、预算和任务运行状态；服务构造不替代这些检查。

每次 start 都消费一个已持久记录的 Dispatch 授权，并匹配宿主调用 ID、模型调用 ID、工具名和参数摘要。未记录、参数被替换、重复 start 或已取消/完成的待启动授权都不能执行。工具记录目录必须位于项目之外。

路径使用既有可移植相对路径校验，拒绝绝对路径、上级跳转、Windows 设备名、流及控制字符；额外拒绝短文件名别名用的波浪号，深度最多64。常见凭证目录/文件（例如 .env、.ssh、.aws、credentials、auth.json、DPAPI文件）和 .git 不可访问。批准的 worker 可执行文件及所有独立验证器的可执行文件、输入文件不能写入。

项目与祖先目录句柄在服务生命周期内保持打开；子目录在单次操作内保持打开，拒绝 reparse。文件通过 OPEN_REPARSE_POINT 打开并校验实际句柄元数据，拒绝非普通文件、reparse和多个硬链接。读取句柄拒绝并发写入/删除，写入句柄独占；已打开的冲突写句柄会使操作失败。这里是工具权限边界，不是对任意同用户程序的 OS 沙箱。

## 文件操作

`cerulean_read_file(path, offset)`：文件最多1MiB，每次最多8192字节，按 UTF-8 边界返回 content、nextOffset、总字节数和完整文件 SHA-256。偏移越界、落在字符中间或非UTF-8文件拒绝。

`cerulean_write_file(path, content, expectedSha256)`：单次内容最多48KiB，禁止NUL；不存在文件必须传 `absent` 并使用 create_new；已有文件必须提供当前完整 SHA-256。独占句柄内先读取并校验版本，匹配后才写入、调整长度并 sync_all。版本冲突保留用户原内容。允许在受控父目录中创建缺失子目录。

参数字段严格解析，不接受额外字段。预执行取消或控制端关闭返回取消错误；丢弃尚未轮询的文件 future 不会写入，既有 Dispatch 仍为 unresolved，不能重放。

## 当前实现限制

文件I/O在future轮询中同步执行，大小有界、无脱离所有者的后台写线程；慢盘或异常文件系统可延迟控制消息处理，尚无硬性 I/O 时延保证。取消不能撤销已完成的写入。

已有文件采用独占句柄内原地写入。现已增加 [写入前像与恢复核查](OMP-WRITE-EVIDENCE-V1.md)，并完成新建/覆盖共八个实际进程终止位置验证。中断仍可能留下部分项目内容；已持久保存的原文/目标可供核查，但用户复核后的还原与原子发布尚未实现。创建父目录后后续失败也可能留下空目录。

尚未提供目录浏览、局部编辑/大文件修改、二进制文件、删除/重命名和命令执行。后续必须补齐适合真实编程任务的操作集，不能将这两个基础工具当作整个编程能力已完成。生产 RuntimeHost/omp_execution 尚未选择此服务，凭证和真实模型调用未参与本批测试。

## 验证证据

七组测试覆盖实际创建/读取/更新、用户并发改动导致版本冲突、目录与路径越界、已有硬链接和目录junction拒绝、只读权限、已批准验证输入保护、批准/模型不匹配、参数摘要替换、UTF-8分块和偏移、冲突句柄、启动前取消、future丢弃及重复启动。

联合测试经过协议协商、注册、目录复核、prompt、真实文件写/读及结果回传；回传时对应 Result 记录已经落盘且摘要与实际RPC结果一致，结束后重开原工具记录仍有两次已完成调用。对端是测试模拟器，不是实际 OMP 模型；该测试不证明真实模型会选择正确工具。

初版遗漏一个函数闭合括号，已修复；首轮五项测试中链接夹具在服务已固定目录后才创建，触发Windows共享冲突，改为启动服务前建立链接后通过。失败日志保留。最终回归统计、源码选择集和后续事项见每日交接。

后续存储布局：新文件服务目录以events/存放工具journal，以writes/存放每次写入的原文/目标及绑定记录；此前原型目录不补造历史备份。
