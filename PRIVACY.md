# 隐私说明 / Privacy notice

## 简体中文

CeruleanLonging 是本地优先的 Windows 工作台。项目配置、需求、计划、执行记录、验证结果和交接资料保存在使用者电脑上的工作台数据目录。备份可能包含项目内容与受保护的配置，应由使用者妥善保管。

使用者配置在线模型、命令行工具或外部桌面工具，并批准和启动相应任务时，所需的提示、文件片段、任务状态和工具结果会交给指定服务或工具处理。API 凭证用于对应服务的认证。服务端可能保存请求和计费用量，其留存、跨境处理及删除规则由各服务自己的隐私条款决定。本地暂停或删除记录不能保证远端请求取消或远端数据删除。

工作台在 Windows 下保护本地凭证；这不能防止已获得使用者账户权限的软件访问数据。分享日志、备份、截图或 Issue 前，请移除密钥、令牌和私人项目内容。向项目 QQ 群或 GitHub 提交反馈是使用者的主动分享行为。

导入 Markdown 并启用主指挥自动提炼时，选择的文档会分段发送到已保存的主指挥 API 服务，可能计费；这发生在确认将结果填入草稿之前。原文分段、模型引用和提炼记录会保留在本地调用记录中。请在选择文档前确认它适合交给所配置的服务处理；取消读入不会撤回已发送的内容。

Microsoft WebView2 以及使用者启用的模型、CLI 和桌面应用具有各自的数据处理行为。使用前请查阅 [Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement) 和所配置供应商的官方隐私政策。第三方中转站由其运营者处理请求，不应据模型标签认为请求已经直接交给官方服务。

源码、发布材料、问题反馈和更新说明托管于 GitHub。SignPath 申请及签名工作由维护者办理，不要求最终使用者向 SignPath 提交自己的模型密钥。

## English

CeruleanLonging is a local-first Windows workbench. Project configuration, requirements, plans, execution records, verification results, and handoff material are stored in the workbench data directory on the user's computer. Backups may include project content and protected configuration and should be handled accordingly.

When users configure an online model, command-line tool, or external desktop tool and approve and start related tasks, the required prompts, file excerpts, task state, and tool results are processed by the selected service or tool. API credentials authenticate with their corresponding services. Providers may retain requests and billing usage; their own privacy terms govern retention, cross-border processing, and deletion. Local cancellation or record deletion does not guarantee remote cancellation or remote deletion.

Local credentials are protected on Windows, but software with access to the user's account may still access data. Remove keys, tokens, and private project content before sharing logs, backups, screenshots, or issues. Posting feedback to the project's QQ group or GitHub is a user-initiated disclosure.

When importing Markdown with automatic chief refinement, the selected document is sent in segments to the saved chief API service and may incur charges, before you confirm inserting the result into the draft. Source segments, citations and refinement records remain in local call records. Check that a document is suitable for the configured service before selecting it; cancelling import does not retract content already sent.

Microsoft WebView2 and the models, CLIs, and desktop applications enabled by users have their own data-processing behavior. Review the [Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement) and the configured providers' official privacy policies. A relay operator handles relay requests; a model label does not establish direct official-provider access.

GitHub hosts source code, releases, issue reports, and update information. The maintainer handles SignPath applications and signing; end users do not need to provide their model API keys to SignPath.
